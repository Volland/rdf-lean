# Project

LeanRDF: a Lean 4 library with a native RDF 1.1 model and formal entailment semantics, where Elpi searches and a verified Lean checker decides. Managed with the `tg` CLI; run `tg check` to validate it.

- [[changes]] — the milestones as OpenSpec changes
- [[code-ontology]] — shared vocabulary of intent types and typed edges between intent and code
