# LeanRDF design

The design lives in the typed graph under `tg.md/`, not in this file:

- `tg.md/decisions.md`: architecture decisions with their reasons and rejected alternatives
- `tg.md/constraints.md`: W3C and toolchain rules the design answers to
- `tg.md/simplifications.md`: departures from the W3C texts (`-- SIMPLIFICATION:` in code)
- `tg.md/integration-contract.md`: how LeanRDF uses lean-elpi
- `tg.md/changes.md`: milestones, each an OpenSpec change in `openspec/changes/`

Read it with `tg search`, `tg section` and `tg cypher`.
