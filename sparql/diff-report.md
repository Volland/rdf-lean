Generated by `scripts/sparql-diff.sh` with oxilite 0.9.1, on the evaluation tests of `sparql/SparqlTests/data/sparql11` (254 tests). Both engines get the same dataset as N-Quads; answers are compared as multisets up to blank-node renaming. An oxilite difference may also come from how the dataset reaches oxilite (one N-Quads file, the default graph as loaded), so each one is a lead to check in oxilite, not a verdict.
